# i18n (contract, v2 after review)

- Files: `web/src/i18n/<locale>.json`, a flat `{ "key": "string" }`.
  - `en`: complete, the source of truth.
  - `es` and `hi`: UI chrome and headlines, after the gate.
  - `ar` (RTL): last.
- Keys:
  - `ui.*` for chrome.
  - `story.<story-id>.title` for titles.
  - `story.<story-id>.<scene-id>.<beat-id>.<lens>` for beat text. Beat ids must be unique within a scene; a test checks it.
- **One fallback rule, in this order:**
  1. The requested locale and lens.
  2. `en`, same lens.
  3. The requested locale, `public` lens.
  4. `en`, `public`.
- Every beat must have an `en` `public` string (a test checks it). This is why `story.schema.json` requires `text.public`.
- Never translated: quotes, source labels, PSI field names, investigation acronyms. Numbers with units are formatted, not translated.
- `ar` sets `dir="rtl"` on `<html>`. The stage and its axes stay left-to-right.
- Translations are AI-drafted and disclosed in the README.
- Tests:
  - Every key used in `stories/*.json` exists in `en`.
  - No locale has keys that `en` lacks.
